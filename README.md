🐞 Bug Tracker v2 – MERN Stack with Authentication
📌 Overview
This is the second version of my Bug Tracker project, built as part of my learning by building journey.
Unlike version 1 (where all users saw the same tickets), this version introduces authentication and authorization. Now each user can sign up, log in, and manage their own tickets securely.

🚀 Tech Stack
JavaScript

Node.js

Express

MongoDB Atlas (cloud database hosting)

Mongoose (ODM for MongoDB)

React (frontend UI library)

JWT Authentication (JSON Web Tokens for secure login)

✨ Key Features
Authentication & Authorization – Users must log in to access protected routes.

User‑Scoped Tickets – Each user only sees tickets they created (user_id attached to each bug).

Secure API Routes – Protected with Bearer tokens to prevent unauthorized access.

Hooks & Context – Custom hooks (useLogin, useLogout, useSignup, useAuthContext) manage state and handle requests.

Error Handling – Login/signup errors are displayed clearly in the UI.

🧠 What I Learned
How to integrate JWT authentication into a MERN app.

How to use React Context + custom hooks for global state management.

How to protect Express routes with middleware.

How to associate users with data in MongoDB using user_id.
